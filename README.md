# Alaa Ahmed Noman | Personal Portfolio

A personal portfolio website built with React.js to showcase my skills, academic background, achievements, certificates, and projects as an Information Technology student aspiring to become a Software Engineer.

## About the Project

This portfolio introduces me, highlights my technical skills and academic achievements, and showcases the projects I have worked on. It also provides visitors with a direct way to contact me.

## Features

- Responsive design for different screen sizes.
- Dark and light mode.
- Projects showcase.
- Skills section.
- Education and academic achievements.
- Certificates gallery.
- Contact form with input validation.
- React Router for navigation between pages.
- Direct email messaging through the contact form.
- EmailJS integration for sending visitor messages.

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- React Router
- EmailJS

## Installation and Setup

Clone the repository:

```bash
git clone https://github.com/alaaahmedn7/react-portfolio.git
```

Navigate to the project directory:

```bash
cd react-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Build

To build the project for production:

```bash
npm run build
```
